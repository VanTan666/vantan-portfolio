## About

A compact, responsive personal homepage built around one idea: introduce the work without getting in its way. It presents my focus on Swift and SwiftUI through a clean editorial layout and a small animated code scene.

## Highlights

- Responsive layout for desktop and mobile
- Light and dark themes
- Animated SwiftUI code example with pause control
- Reduced-motion support and keyboard-friendly navigation
- No framework or build step — plain HTML, CSS, and JavaScript
- Published with GitHub Pages at [vantan.tech](https://vantan.tech)

## Run locally

Serve the repository with any static file server, then open it in a browser. For example:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
